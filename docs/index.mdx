`@corpora/ui` is a shadcn-style library (base-ui, style `base-mira`) plus its docs site, in one Vite + React codebase under `react/`. Components map 1:1 to Sketch symbol masters and are grouped by feature spec.

## Install

```bash
cd react && bun install
make check   # tsc -b --noEmit + eslint
bun test     # from react/
```

Mount `ExegiaProvider` once at the app root; every stateful chat component keys its Jotai atoms by instance id below it.
