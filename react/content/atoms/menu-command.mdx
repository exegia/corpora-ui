## Usage

```tsx
import { MenuCommand } from "@exegia/corpora-ui"

<MenuCommand items={[{ id: "web", label: "Web search", description: "Real-time news", icon: <Globe />, trailing: "Connected" }]} onSelect={run}>
  <Button size="icon-lg" aria-label="Attach">+</Button>
</MenuCommand>
```

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| items (required) | MenuCommandItem[] | — | &#123; id, label, description?, icon?, trailing?, href?, disabled?, onSelect? &#125;. |
| onSelect | (item) =&gt; void | — | Fires after the row's own onSelect. |
| side / align | Positioner side / align | "top" / "start" | MenuCommand only. |
