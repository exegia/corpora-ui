## Usage

```tsx
import { FileBadgeTei, FileWordmarkPdf } from "@exegia/corpora-ui"

<FileBadgeTei />                         // 64×64, follows the app's dark class
<FileBadgeTei size={96} />               // any size
<FileWordmarkPdf title={null} />         // decorative: aria-hidden
<div className="dark">
  <FileBadgeTei />                       {/* dark artwork, regardless of theme */}
</div>
```

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| size | number &#124; string | 64 | Rendered width and height. |
| title | string &#124; null | e.g. "TEI file" | Accessible name (role=img + aria-label). Pass null to mark the icon decorative — it becomes aria-hidden with role=presentation. |
| className / …props | SVGProps&lt;SVGSVGElement&gt; | — | Everything else is forwarded to the root &lt;svg&gt;. Theme switching needs no props: the light layer is `dark:hidden`, the dark layer `hidden dark:inline`, so the artwork follows whatever drives the app's `dark` variant — scope a `dark` class to force one theme. |
