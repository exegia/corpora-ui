---
title: Atoms
description: Foundational controls, typography, and identity components.
---

Each atom includes an interactive story, usage, and examples.

- [Button](/atoms/button): Displays a button or a component that looks like a button.
- [Input](/atoms/input): Displays a form input field.
- [Label](/atoms/label): Accessible label paired with a form control.
- [Field](/atoms/field): Form field wrapper wiring label, control, description and error together.
- [Checkbox](/atoms/checkbox): Control for toggling a boolean, with indeterminate support.
- [Separator](/atoms/separator): Visually separates content horizontally or vertically.
- [Card](/atoms/card): Surface with header, panel and footer sections.
- [Frame](/atoms/frame): Muted wrapper that raises cards into framed panels, with header/footer strips.
- [Textarea](/atoms/textarea): Multi-line text input.
- [OTP Field](/atoms/otp-field): One-time-passcode input with per-character slots.
- [Input Group](/atoms/input-group): Input with leading/trailing addons (icons, text, buttons).
- [Reference](/atoms/reference): Reference chip pointing at the node, passage or source a suggestion is grounded in, with an optional hover preview of the passage.
- [Text](/atoms/text): Typography primitive for body copy, labels and captions.
- [Bubble](/atoms/bubble): Chat bubble atom: an inner-shadowed message surface with sender, recipient and ai variants, an author header (avatar, name, time, role badge), a glass reaction pill hanging off the corner and hover-revealed message actions.
- [Avatar](/atoms/avatar): Identity avatar: an image when one is given, initials otherwise, with a presence badge, a loading skeleton, and story-ring audio states.
- [File icons](/atoms/file-icons): Fourteen file-format icons — seven formats in badge and wordmark families. Each embeds light and dark artwork and switches on Tailwind's dark variant: pure CSS, no props, no hydration flash.
- [Chat atoms](/atoms/chat-atoms): Attachment primitives from the exegia-ui Sketch library: IconTile, Thumbnail, AvatarHandle, Remove/Play/Send/Add buttons, FileTypeBadge, Favicon, Waveform, QuoteRail, DurationPill. Colours come from the chat tokens, so light and dark need no props.
- [Menu command](/atoms/menu-command): Command rows for a menu popup: icon · label · description · trailing status. MenuCommand wires a trigger to the popup; MenuCommandList drops into any MenuPopup.
