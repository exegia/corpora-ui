## Usage

```tsx
import { Checkbox } from "@exegia/corpora-ui"

<Checkbox defaultChecked />
```

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| indeterminate | boolean | false | Renders the mixed state. |
| sound | boolean | true | Emit the cuelume toggle cue. Silent until the app calls bindSounds(). |
