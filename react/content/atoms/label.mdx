## Props

### Sound options

- **true**: Emit the cuelume hover tick (default).
- **false**: Silent — the labelled control owns the interaction cue.

## Usage

```tsx
import { Label } from "@exegia/corpora-ui"

<Label htmlFor="email">Email</Label>
```

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| sound | boolean | false | Opt into the cuelume hover tick. Off by default — the labelled control owns the interaction cue. Silent until the app calls bindSounds(). |
