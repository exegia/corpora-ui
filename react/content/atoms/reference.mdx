## Usage

```tsx
import { Reference } from "@exegia/corpora-ui"

;<Reference href="/corpus/iliad/1.12" preview={passage}>
  Iliad 1.12
</Reference>
```

## API reference

| Prop    | Type      | Default | Description                                                             |
| ------- | --------- | ------- | ----------------------------------------------------------------------- |
| href    | string    | —       | Renders the chip as a link.                                             |
| preview | ReactNode | —       | The passage, shown in a PreviewCard on hover / focus. Omitted, no card. |
