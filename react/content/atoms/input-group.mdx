## Usage

This UI module is also available from `@exegia/corpora-ui/ui/input-group`.

```tsx
import {
  InputGroup,
  InputGroupAddon,
  InputGroupInput,
} from "@exegia/corpora-ui"

<InputGroup>
  <InputGroupAddon>
    <SearchIcon />
  </InputGroupAddon>
  <InputGroupInput placeholder="Search…" />
</InputGroup>
```
