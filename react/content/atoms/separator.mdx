## Props

### Orientation options

- **horizontal**: Separates content horizontally (default).
- **vertical**: Separates content vertically.

## Usage

```tsx
import { Separator } from "@exegia/corpora-ui"

<Separator />
<Separator orientation="vertical" />
```

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| orientation | "horizontal" &#124; "vertical" | "horizontal" | Direction of the separator. |
