## Props

| Prop                      | Type                            | Default | Description                                     |
| ------------------------- | ------------------------------- | ------- | ----------------------------------------------- |
| `statuses` (required)     | `{ id, label, tone }[]`         | —       | Filter pills and status dot colours.            |
| `columns` (required)      | `{ key, header, className? }[]` | —       | Table columns; the status column renders a dot. |
| `rows` (required)         | `{ id, status, … }[]`           | —       | Rows; filtered by status.                       |
| `filter / onFilterChange` | `string \| null`                | —       | Controlled filter; null is All.                 |

## Example

<Demo />

```tsx
import { FilterTable } from "@exegia/corpora-ui"

<FilterTable statuses={statuses} columns={columns} rows={rows} />
```
