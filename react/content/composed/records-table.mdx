## Usage

```tsx
import { RecordsTable } from "@exegia/corpora-ui"

<RecordsTable rows={rows} onSortChange={sortBy} />
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `rows` (required) | `RecordsRow[]` | — | id, name, initial, tags, lastInteraction, strength. |
| `selected / onSelectionChange` | `ReadonlySet<string>` | — | Controlled selection. |
| `onSortChange` | `(column) => void` | — | Header sort control; the design shows no direction. |
| `maxTags` | `number` | `2` | Tags shown before +N. |
