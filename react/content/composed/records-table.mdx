## Props

| Prop                           | Type                  | Default | Description                                         |
| ------------------------------ | --------------------- | ------- | --------------------------------------------------- |
| `rows` (required)              | `IRecordsRow[]`        | —       | id, name, initial, tags, lastInteraction, strength. |
| `selected / onSelectionChange` | `ReadonlySet<string>` | —       | Controlled selection.                               |
| `onSortChange`                 | `(column) => void`    | —       | Header sort control; the design shows no direction. |
| `maxTags`                      | `number`              | `2`     | Tags shown before +N.                               |

## Example

<Demo />

```tsx
import { RecordsTable } from "@exegia/corpora-ui"

<RecordsTable rows={rows} onSortChange={sortBy} />
```

The selection and company columns stay pinned during horizontal scrolling. Set `stickyHeader` and constrain the height (for example, `className="max-h-64"`) to keep the header visible while scrolling vertically. Scrollbars are hidden; trackpad, wheel, touch, and keyboard scrolling remain available.
