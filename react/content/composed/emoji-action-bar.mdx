## Props

| Prop            | Type                                | Default           | Description                                                                                                                                                                                                                                                                                                                        |
| --------------- | ----------------------------------- | ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `onEmojiSelect` | `(emoji: { emoji, label }) => void` | —                 | Fires for both a quick reaction and a pick from the full picker, so a caller wires one handler.                                                                                                                                                                                                                                    |
| `reactions`     | `readonly Emoji[]`                  | `QUICK_REACTIONS` | The quick row. frimousse cannot render a subset — EmojiPicker.Root exposes only columns/skinTone/locale/emojiVersion/emojibaseUrl/sticky, and its list is virtualized on fixed-height rows, so a fixed list is the only way to show just a few. It also costs no network request: the emoji CDN is fetched only if More is opened. |
| `hideMore`      | `boolean`                           | `false`           | Drops the trailing More action, leaving the quick row only — nothing then loads emoji data at all.                                                                                                                                                                                                                                 |

## Example

import { EmojiActionBar } from "@exegia/corpora-ui"
