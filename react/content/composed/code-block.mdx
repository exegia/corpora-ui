## Usage

```tsx
import { CodeBlock } from "@exegia/corpora-ui"

<CodeBlock filename="churn.ts" code={source} onCopy={copy} />
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `code` (required) | `string` | — | Source; split on newlines. |
| `filename` | `ReactNode` | — | Header label. |
| `diff` | `{ type?: "add" \| "remove", text }[]` | — | Enables the Diff view. |
| `view / defaultView / onViewChange` | `"code" \| "diff"` | — | Controlled or uncontrolled. |
| `onCopy` | `(code) => void` | — | Copy button. |
| `keywords` | `string[]` | — | Extra keywords to tint. |
