## Usage

```tsx
import { SocialProviders } from "@exegia/corpora-ui"

<SocialProviders action="login" onSelect={(provider) => signIn(provider)} />
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `providers` | `("google" \| "apple" \| "github" \| "x")[]` | `["google", "apple", "github"]` | Providers to render, in order. |
| `action` | `"login" \| "signup" \| "continue"` | `"continue"` | Verb used in the button labels. |
| `layout` | `"stack" \| "row"` | `"stack"` | Full-width labeled buttons or an icon-only row. |
| `loadingProvider` | `SocialProvider \| null` | `null` | Marks one provider as loading and disables the rest. |
