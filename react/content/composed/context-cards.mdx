## Usage

```tsx
import { ContextCards } from "@exegia/corpora-ui"

<ContextCards count={32} cards={[{ title: "Vendor onboarding rule", meta: "290 characters", snippet: "…", file: { name: "SOP.pdf", type: "PDF" } }]} />
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `cards` (required) | `ContextCard[]` | — | title, meta, snippet, file &#123; name, type &#125;. |
| `header / count` | `ReactNode` | — | Defaults to All chunks and cards.length. |
| `onOpen` | `(card, index) => void` | — | File pill click. |
