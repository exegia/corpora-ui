## Usage

```tsx
import { ResearchAnswer } from "@exegia/corpora-ui"

<ResearchAnswer content="…" source="Iliad · Homer corpus" date="c. 750 BCE" authors="Homer" onCopyCitation={copy} />
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `content` (required) | `ReactNode` | — | The answer. |
| `kicker / kickerSub` | `ReactNode` | — | Header row. |
| `source / date / authors` | `ReactNode` | — | Meta columns; omitted ones are hidden. |
| `onCopyCitation / onShare / onAddToList` | `() => void` | — | Actions. Add to list behaviour is not designed — the callback is all the card does. |
