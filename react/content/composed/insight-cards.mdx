## Usage

```tsx
import { InsightCards, InsightEntity } from "@exegia/corpora-ui"

<InsightCards insights={[{ summary: <>Worst performer in <InsightEntity>Creamery</InsightEntity>…</>, stats: [...], snapshot: { data, series } }]} />
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `insights` (required) | `Insight[]` | — | summary, stats (StatProps[]), snapshot &#123; data, series &#125;, allocation &#123; label, value, initials, segments[] &#125;, followUp. |
| `index / defaultIndex / onIndexChange` | `number` | — | Which insight is shown. |
| `onFollowUp` | `(text) => void` | — | Follow-up pill. |
