## Props

| Prop                                | Type                            | Default | Description                                                          |
| ----------------------------------- | ------------------------------- | ------- | -------------------------------------------------------------------- |
| `source` (required)                 | `string`                        | —       | Markdown text (headings, paragraphs, lists, inline and fenced code). |
| `markdownId`                        | `string`                        | —       | Stable id for the view atom; unnamed cards use useId().              |
| `view / defaultView / onViewChange` | `"preview" \| "markup"`         | —       | Controlled or uncontrolled pane.                                     |
| `onCopy / onExpand`                 | `(source) => void / () => void` | —       | Header icon buttons.                                                 |
| `bare`                              | `boolean`                       | `false` | Drop the card border.                                                |

## Example
