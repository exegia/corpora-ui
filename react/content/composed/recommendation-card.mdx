## Props

| Prop                                    | Type                                                | Default  | Description                                                   |
| --------------------------------------- | --------------------------------------------------- | -------- | ------------------------------------------------------------- |
| `title / description` (required)        | `ReactNode`                                         | —        | Title in the header; description inside the collapsible body. |
| `entity / descriptionSuffix / leadTime` | `{ name, initials?, src? } / ReactNode / ReactNode` | —        | Inline details within the collapsible description.            |
| `options / onSelectOption`              | `IRecommendationOption[] / (index) => void`         | —        | Rows under Other options.                                     |
| `confidence`                            | `"high" \| "medium" \| "low"`                       | `"high"` | Footer signal.                                                |
| `onAccept / onAlternatives`             | `() => void`                                        | —        | Footer buttons.                                               |
