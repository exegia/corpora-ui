## Props

| Prop                                    | Type                                                | Default  | Description                                     |
| --------------------------------------- | --------------------------------------------------- | -------- | ----------------------------------------------- |
| `title / description` (required)        | `ReactNode`                                         | —        | Header and the sentence before the entity pill. |
| `entity / descriptionSuffix / leadTime` | `{ name, initials?, src? } / ReactNode / ReactNode` | —        | Inline pills.                                   |
| `options / onSelectOption`              | `RecommendationOption[] / (index) => void`          | —        | Rows under Other options.                       |
| `confidence`                            | `"high" \| "medium" \| "low"`                       | `"high"` | Footer signal.                                  |
| `onAccept / onAlternatives`             | `() => void`                                        | —        | Footer buttons.                                 |
