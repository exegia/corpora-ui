## Usage

```tsx
import { PasswordInput } from "@exegia/corpora-ui"

<PasswordInput showStrength autoComplete="new-password" />
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `visibilityToggle` | `boolean` | `true` | Show the eye toggle button. |
| `showStrength` | `boolean` | `false` | Show the animated strength meter and requirements. |
| `sound` | `boolean` | `true` | Reveal/hide cues on the visibility toggle. Silent until bindSounds(). |
