## Props

| Prop                    | Type                             | Default                        | Description                                                                                         |
| ----------------------- | -------------------------------- | ------------------------------ | --------------------------------------------------------------------------------------------------- |
| `paragraphs` (required) | `(string \| StreamingToken[])[]` | —                              | Each paragraph is words or tokens; `{ cite, title?, description?, href? }` renders an InlineSource. |
| `streaming`             | `boolean`                        | `false`                        | Animate the reveal; reduced motion shows everything at once.                                        |
| `wordMs`                | `number`                         | `--stream-gap` (60ms fallback) | Override the gap between revealed words in milliseconds.                                            |

## Example

<Demo />

```tsx
import { StreamingText } from "@exegia/corpora-ui"

<StreamingText
  streaming
  paragraphs={[
    "The Iliad opens with an invocation to the Muse.",
    [{ cite: "Iliad 1.1", title: "Opening invocation" }],
  ]}
/>
```
