## Usage

```tsx
import { Logo } from "@exegia/corpora-ui"

<Logo name="Corpora" href="/" mark={<BrandMark />} />
<Logo name="Corpora" variant="mark" />  // icon rail: mark only
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `name` (required) | `string` | — | Brand name. Labels the logo for AT (and the link, when href renders one), drives the default wordmark, and the monogram tile when no mark is given. |
| `mark` | `ReactNode` | — | Custom mark — an inline SVG sized to fill its box. Wins over src. |
| `src` | `string` | — | Image URL for the mark. Decorative — name labels the logo. Without mark or src, a monogram tile derived from name renders instead. |
| `wordmark` | `ReactNode` | — | Wordmark content. Defaults to name. |
| `variant` | `"full" \| "mark"` | `"full"` | mark folds the wordmark away (width, opacity, slight x) and hides it from AT; the root keeps the accessible name. Reduced-motion aware. |
| `href` | `string` | — | Renders the lockup as an anchor named by name — the usual "mark goes home" affordance. |
