## Usage

```tsx
import { AuthFlowBlock } from "@exegia/corpora-ui"

<AuthFlowBlock
  onLogin={async ({ email, password }) => {
    const outcome = await api.signIn(email, password)
    return outcome.mfa
      ? { verify: { identifier: email } }
      : { user: outcome.user }
  }}
  onVerifyCode={async (code) => ({ user: await api.verify(code) })}
  onRequestReset={({ email }) => api.sendResetLink(email)}
/>

// The flow lives in the store — drive or observe it from anywhere:
//   useAuthFlowActions().goToStep("signup")
//   useAuthSession().user
```

## API notes

| Prop                                                                                                                           | Type                                                                                           | Default                | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------- | ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| flowId                                                                                                                         | <code>string</code>                                                                            | <code>"default"</code> | Which flow instance to orchestrate. A re-auth modal passes its own id and coexists with the main flow; `useAuthFlowActions(flowId)` drives the same instance from anywhere.                                                                                                                                                                                                                                                                                                                               |
| onLogin / onSignup / onVerifyCode / onRequestReset / onUpdatePassword / onProviderSelect / onOnboardingComplete / onResendCode | <code>(data) =&gt; TAuthFlowDirective &#124; Promise&lt;TAuthFlowDirective&gt</code>            | —                      | The API boundary, one handler per step submit. Resolve with a directive to move the flow: `&#123; user &#125;` completes it AND signs the session in (one atomic write), `&#123; verify: &#123; identifier &#125; &#125;` records the destination and moves to the code step, `&#123; step &#125;` navigates, and `void` stays put (the block shows its own success). Reject to render the block's own error state — the orchestrator never mirrors transients into the store.                            |
| logo / accent / providers                                                                                                      | <code>ReactNode / TAuthAccent / TSocialProvider[]</code>                                         | —                      | Branding handed to every step's card; `providers` feeds the login and signup steps.                                                                                                                                                                                                                                                                                                                                                                                                                       |
| steps / renderStep / success                                                                                                   | <code>IAuthFlowStepOverrides / (step, flow) =&gt; ReactNode &#124; undefined / ReactNode</code> | —                      | Escape hatches, in escalating order: `steps` merges prop overrides over the wiring of one block (`&#123; login: &#123; onSignup: undefined &#125; &#125;` unhooks a default navigation link), `renderStep` replaces a whole step's UI (return undefined to keep the default), and `success` swaps the built-in completion card (`successTitle` / `successDescription` retitle it instead). Navigation between steps (login ↔ signup, forgot password, back from verification) is pre-wired to `goToStep`. |
