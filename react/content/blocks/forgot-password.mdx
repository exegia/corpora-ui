## Usage

```tsx
import { ForgotPasswordBlock } from "@exegia/corpora-ui"

;<ForgotPasswordBlock onSubmit={({ email }) => sendResetLink(email)} />
```

## API notes

| Prop          | Type                                                         | Default | Description                                                                                                                   |
| ------------- | ------------------------------------------------------------ | ------- | ----------------------------------------------------------------------------------------------------------------------------- |
| logo          | <code>React.ReactNode</code>                                 | —       | Brand mark rendered above the title. Omitted leaves no logo row at all.                                                       |
| accent        | <code>"corpora" &#124; "exegia"</code>                       | —       | Brand accent for the primary action — corpora is a solid #E8B124, exegia a purple gradient. Omit to keep the default primary. |
| onSubmit      | <code>(&#123; email &#125;) =&gt; Promise&lt;void&gt;</code> | —       | Reject to surface the error state.                                                                                            |
| onBackToLogin | <code>() =&gt; void</code>                                   | —       | Footer back-link handler.                                                                                                     |
