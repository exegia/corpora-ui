## Usage

```tsx
import { PasskeySignInBlock } from "@exegia/corpora-ui"

;<PasskeySignInBlock
  available={capability.usable}
  onSignIn={signInWithPasskey}
/>
```

## API notes

| Prop         | Type                                                                               | Default                               | Description                                                                                                               |
| ------------ | ---------------------------------------------------------------------------------- | ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| available    | <code>boolean</code>                                                               | <code>true</code>                     | Whether this device can use passkeys. false renders nothing at all — a button guaranteed to fail is worse than no button. |
| label        | <code>string</code>                                                                | <code>"Sign in with a passkey"</code> | Button label.                                                                                                             |
| onSignIn     | <code>() =&gt; Promise&lt;&#123; cancelled?: boolean &#125; &#124; void&gt;</code> | —                                     | Reject (or throw) to show the inline error. Resolve with &#123; cancelled: true &#125; to return silently to idle.        |
| fallbackHint | <code>React.ReactNode</code>                                                       | —                                     | Shown under an error, pointing at the remaining sign-in methods.                                                          |
