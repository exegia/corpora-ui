## Usage

```tsx
import { UpdatePasswordBlock } from "@exegia/corpora-ui"

;<UpdatePasswordBlock
  onSubmit={async ({ password }) => updatePassword(password)}
/>
```

## API notes

| Prop        | Type                                                            | Default        | Description                                                                                                                   |
| ----------- | --------------------------------------------------------------- | -------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| logo        | <code>React.ReactNode</code>                                    | —              | Brand mark rendered above the title. Omitted leaves no logo row at all.                                                       |
| accent      | <code>"corpora" &#124; "exegia"</code>                          | —              | Brand accent for the primary action — corpora is a solid #E8B124, exegia a purple gradient. Omit to keep the default primary. |
| minStrength | <code>number</code>                                             | <code>4</code> | Strength (0-4) the new password must reach before the confirm field is revealed. 0 disables the gate.                         |
| onSubmit    | <code>(&#123; password &#125;) =&gt; Promise&lt;void&gt;</code> | —              | Reject (or throw) to show the error state with the error message.                                                             |
| onDone      | <code>() =&gt; void</code>                                      | —              | Adds a Continue link to the success panel. Omit to end on the panel.                                                          |
