## Source layers

- `src/components/ui` — atoms.
- `src/components/composed` — components.
- `src/components/blocks` — blocks.
- `src/state` — the shared Jotai store and provider.

## State model

Stateful components never add a second provider. They use instance-keyed Jotai atom families and expose read/write hooks from the same module:

- `use<Feature>State(id)` reads the component state.
- `use<Feature>Actions(id)` writes without subscribing to unrelated changes.
- unnamed instances are dropped on unmount; explicit ids survive route changes.

## Documentation model

Fumapress renders `.md` and `.mdx` files in `content/` as pages. Frontmatter supplies titles and descriptions; `meta.json` controls sidebar ordering.

- `content/atoms`, `content/composed`, and `content/blocks` own component documentation, usage examples, and prop notes.
- `*.story.tsx` files beside components define previews and TypeScript-derived prop controls.
- `src/registry/demos` supplies larger worked examples imported by MDX pages.
- `src/pages` is reserved for custom designs that need a React route.

To document a component, add its MDX page and a story, then list the page in the category's `meta.json`. No TypeScript documentation registry is needed.
