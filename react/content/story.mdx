## Write your own

Create a `<name>.story.tsx` file next to the component and render it from any
MDX page:

```tsx title="src/components/ui/button.story.tsx"
"use client"

import { defineStory } from "@/registry/story"

import { Button } from "./button"

export const story = defineStory({
  Component: Button,
  args: {
    initial: {
      children: "Button",
      variant: "default",
      size: "default",
    },
  },
})

export const Preview = story.WithControl
```

```mdx title="content/my-page.mdx"
import { Preview } from "@/components/ui/button.story"

<Preview />
```

The `.story` suffix is required — the Vite plugin only transforms files
matching `*.story.{js,jsx,ts,tsx}`.

Export the preview component directly from the client story module so Fumapress can render it from server-rendered MDX. Keep callbacks and interactive state in the story.
