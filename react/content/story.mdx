Stories are interactive playgrounds generated from a component's TypeScript
props. Tweak the controls to explore the `Button` atom:

<story.WithControl />

## Write your own

Create a `<name>.story.tsx` file next to the component and render it from any
MDX page:

```tsx title="src/components/ui/button.story.tsx"
import { defineStory } from "@/registry/story"

import { Button } from "./button"

export const story = defineStory({
  Component: Button,
  args: {
    initial: {
      children: "Button",
      variant: "default",
      size: "default",
    },
  },
})
```

```mdx title="content/my-page.mdx"
import { story } from "@/components/ui/button.story"

<story.WithControl />
```

The `.story` suffix is required — the Vite plugin only transforms files
matching `*.story.{js,jsx,ts,tsx}`.
