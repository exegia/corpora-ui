`@exegia/corpora-ui` is a React 19 + Tailwind v4 component library for the [Corpora](https://corpora.exegia.co) apps. It ships three layers:

- **Atoms** — the primitives installed by shadcn.
- **Components** — purposeful compositions that stay unopinionated.
- **Blocks** — opinionated assemblies for complete product surfaces.

Every public component is exported from `@exegia/corpora-ui`, and documentation lives in Markdown and MDX, with interactive previews and prop controls powered by Fumadocs Story.
